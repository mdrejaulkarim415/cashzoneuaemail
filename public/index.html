Is the generated user agent realistic?

The output follows the exact token order used by desktop Chrome on 64-bit Windows. It is suitable for QA, compatibility testing and interface demos. It is not a claim of your current browser identity.

Can I keep the Chrome version selection off?

Yes. Manual selection is optional. With the switch off, every profile uses the default Chrome 155.0.0.0. Turn it on only when you need a specific major version.

Will the same email ever repeat?

No. Before an address is shown, it is atomically reserved in a shared Netlify Blobs registry. The check covers every user of this deployed site, not just your browser. Clearing local history does not release or reuse an address.

Are these email addresses real inboxes?

No. They are realistic-looking, letters-only Gmail addresses created for testing and mock profiles. No inbox is created and no messages can be sent to them. Use generated identities responsibly and follow the rules of any platform you test with.

Where is my generated history stored?

Your profile history stays in this browser’s local storage. For global uniqueness, the server stores only the anonymous Gmail handle and its reservation timestamp in Netlify Blobs—never your clipboard contents or personal data. You can clear the local history at any time.
